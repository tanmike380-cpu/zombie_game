# 东方边境地图：第一张可玩世界切片

## 目标与边界

从战斗压测进入资源和地图玩法。256×256 格、左下角已运营聚落、400 火枪兵、其余地区 5000 僵尸（狂暴尸和爆裂尸）。
这不是已完成的整款游戏，也不是最终写实美术。保留原有人物模型、火枪烟雾、操作、伤害 100、噪声三倍射程。
美术方向：建筑、兵、僵尸参考《帝国时代4》的材质和比例，整体色彩参考《亿万僵尸》。详见 `ART_DIRECTION.md`，不使用两款游戏的资产。

参考：https://www.ageofempires.com/games/age-of-empires-iv 与 https://www.numantiangames.com/TheyAreBillions/

## 打开和操作

Unity 停止 Play，菜单 **Tools > Zombie Game > World > Open Frontier Map**，再 Play。

- 左拖框选；右键移动；A 后左键进攻；Q 巡逻；S 停止。
- F2 或波浪线全选；Ctrl+数字编队，数字召回，双击数字聚焦。
- 方向键移动镜头；滚轮缩放；C 看部队；Home 回基地；F 全图。
- V 是调试开图，不改变真正视野或攻击可见性；H 隐藏帮助；空格暂停。
- B 或单击镇守府选择主基地；训练神机营、扩建农庄/伐木/采石/铁矿/火药/箭坊都从基地面板发起。F2 返回部队。
- 已删除 E 占领和部队栏的工坊开关。现有工坊持续加工，火药不足时停止射击，补足后恢复。
- 队列上限 8，入队扣资源，取消末项全额退款；出生出口拥堵时保留已付费项目等待。400 初始士兵另有 200 个招募预留位；这不是完整人口系统。
- 六处扩建地基为固定位置，预先纳入 NavMesh 障碍并显示石台/标桩；各可扩建一次，完工增加对应生产设施数量。不是鼠标自由选址或工人搬运系统。

## 清晰度

界面修正：实机发现 Game 开启了 `Low Resolution Aspect Ratios` 且 Scale 为 5×，造成模糊和资源栏/小地图裁出窗口。关闭低分辨率选项、恢复 1× 后完整画面可见。推荐聚焦 Game 后 Shift+Space 最大化，再用游戏内滚轮缩放镜头，而不是调 Game 的 Scale。
资源在最右下，部队栏只保留作战指令和基地入口；选中基地后切换生产面板。45° 斜俯视，角色仍是临时模型，并非已经完成《帝国时代4》级别的美术重制。

按用户指定重新排列：左下小地图；中间显示所选单位兵种图标、数量、总生命与共享 balance 属性，其下为 1–9、0 编队卡片；右下为 3×3 命令面板。Ctrl+数字保存编队后卡片立即更新存活数量；点击召回，双击聚焦。卡片兵种图标是原创火绳枪兵剪影，目前只显示已经实现的神机营，不伪造其他兵种。镜头另有 30° 水平偏角，近景显示所选兵血条，远景保留受伤兵血条以减少绿色条纹遮挡。

没有启用动态分辨率或低分辨率渲染，Retina 支持保留。新相机关闭动态分辨率，4× MSAA，镜头可拉近到 8 格半高。
Game 面板的 Scale 是编辑器显示缩放，不是贴图清晰度：显示 2× 会把渲染结果放大。尽量使用 1×，扩大 Game 面板，再用游戏内滚轮拉近，而不是放大低像素的预览。
人物已做比例和材质分区调整，但仍保留低细节底模，不是完整写实换模。

## 本轮已接通

- 弯曲河道、封闭密林、不可攀登的岩壁；同一份区域数据同时驱动外观和 NavMesh，不存在装饰河可直接穿过的问题。
- 河道北端保留绕行陆路，无桥；密林内部不可通行，不支持砍树开路。
- 基地有指挥所、营房、民居、粮仓、箭坊、火药坊、伐木营等轮廓和道路。
- 六库存：粮食、木材、石料、铁矿、箭矢、火药。基地初始产出与扩建产出受限，资源不枯竭；旧地图资源点暂不提供占领交互。
- 木材→箭矢、铁矿→火药；配方和初始库存都明确为临时值。
- 每发火枪扣 1 火药，扣费成功才产生射击、伤害和噪声。费用来自共享单位 balance。
- 共享 RTS 输入模块从压测移到正式目录；老压测保留兼容组件，避免两套操作逻辑分叉。

## 文件入口

- `Assets/_Game/Scripts/World/FrontierMap.cs`：地图边界、河流、森林、悬崖、聚落位置、资源点和出生。
- `Assets/_Game/Scripts/World/FrontierLandscape.cs`：批量地形几何和屋顶等表现。
- `Assets/_Game/Scripts/World/FrontierGame.cs`：场景协调、镜头、主基地选择和生产完成。
- `Assets/_Game/Scripts/World/HeadquartersProduction.cs`：付费队列、取消退款、重复建筑拒绝。
- `Assets/_Game/Resources/HeadquartersProduction.json`：明确标记 provisional 的训练/建造费用和时长。
- `Assets/_Game/Scripts/World/FrontierEconomy.cs`：产出、加工、扣弹药。
- `Assets/_Game/Resources/FrontierEconomy.json`：这一张场景的临时经济参数源，不复制单位战斗数值。
- `Assets/_Game/Scripts/Controls/RtsBattleInput.cs`：共用框选、命令、编队、小地图。
- `balance/unit_balance.json`：所有单位属性的唯一来源。新增兵种建议值标记 `provisional:true`，未实现的仍不启用；Boss 继续未定。
- `Assets/_Tests/Frontier/Scenes/FrontierMap.unity`：可玩实验场景；可复用系统在 `_Game`，没有正式运行时代码反向依赖测试模块。

## 尚未完成，不能误认为已实现

建筑伤害/感染/维修、自由选址建造、完整人口系统、兵种全 roster、胜负和总攻计时、存档。
资源建筑暂不能被摧毁，因此资源收入目前不会被僵尸截断。原型用于先测生产/探索/弹药，不代表完整经济攻防闭环。
现在仍只有神机营、狂暴尸、爆裂尸在场。其他单位临时数值经用户授权拟定，但还要逐种实现其盾牌、近战、弹药类型、毒液、攻城等机制并测试，不能把现有单位换名字就冒充完成。
战争迷雾目前以人类和主基地半径揭示（同读共享人类视野），不做地形遮挡的视野裁剪；实际攻击 LOS 会被树林/岩壁/建筑阻挡，低矮河面不阻挡射线。

## 验证

HUD 最新布局：左下小地图；中间紧凑单位属性、部队总生命与说明、0–9 编队卡片；右侧 3×3 指令；最右侧六项资源。顶部不再保留资源条或拦截框选。属性区的生命、伤害、射程、攻击间隔、移速、视野与噪音均读取 UnitBalance，明确区分单兵属性和所选部队总生命。未选中单位时隐藏兵种属性。

`ZombieGame.EditorTools.FrontierTools.build_player` 构建 `Builds/Frontier.app`。
启动参数 `-frontierSmoke` 检查全部出生点、全部地形区域中心不可通行、北端绕河路径、无火药拒绝射击、加工恢复供给、运行后无地形侵入。
本轮地图有 297 个阻挡区域（含六个预留扩建地基）。`-frontierSmoke` 还验证基地队列扣费/退款/不足拒绝/出口阻塞、六个设施产出、新兵出生与 F2、共享避让半径。
不要把此测试当成完整万人战斗性能报告；本轮默认 5000 僵尸，下一阶段再针对经济/新兵种做 5000 与 10000 对照。
