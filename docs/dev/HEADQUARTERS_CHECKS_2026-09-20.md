## 自动运行结果

- Frontier 构建通过，无 C# / Shader 编译错误。
- `-frontierSmoke`：400 初始人类 + 200 未部署预留 + 5000 僵尸；所有出生点合法，297 个障碍中心不能通行，绕河走北端陆地。
- `HeadquartersSmoke`：扣费一次、取消全额退款、资源不足/容量不足拒绝、出口受阻保留队列、六项设施完成及重复建造拒绝；新兵合法生成、读取共享属性、被 F2 选中；末尾 geometry=0。仅独立 smoke 进程执行，退出销毁该场景。
- `-rtsSmoke`：原 400 对 10000 场景，通过两支 200 人相隔 64 格收拢、近者分配内圈、障碍绕行、移动/停止/巡逻、框选/编队/聚焦、最新噪声重定向、范围外不唤醒。
- 移速运行采样：人类 3.500，狂暴尸 4.971，爆裂尸 4.900 格/秒（短时采样包含加速；配置目标分别为 3.5/5.2/4.9）。追击距离从 3.5 缩至 1.565。

这些是功能回归，不是新美术版的完整万人帧率报告。加大避让半径提高间距，但不会保证窄口不拥堵；瓶颈的通行能力仍受宽度限制。
