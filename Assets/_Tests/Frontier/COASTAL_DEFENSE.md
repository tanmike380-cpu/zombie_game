# 海岸防守试玩

在原有 `FrontierGame` 上增加布局与模型目录，不是另一套战斗控制器。

## 启动

- 本地试玩：`Builds/CoastalDefense.app`。Unity 场景：`Assets/_Tests/Frontier/Scenes/CoastalDefense.unity`。
- 400 名守军（320 弩手、80 弓箭手）、2000 只僵尸。60 秒准备后总攻；海在营地后方。
- 鼠标框选、右键移动、A 再左键攻击、S 停止、空格暂停、滚轮缩放、Home 回基地。
- F2 / 反引号全选，连按两次聚焦；Ctrl+数字编队。小地图左键拖动镜头。
- 不启用自动走 A。营地三面的墙与建筑可被破坏，缺口由原生 NavMesh carving 打开。
- 守军远程攻击可越过己方墙身；近战、僵尸视线与寻路仍被完整城墙阻挡，普通房屋及地形仍挡弹道。
- 加 `-coastalPaused` 启动会停在准备画面，空格开始，准备计时不会提前消耗。

## 素材与动作

- 新导出源：`Assets/_Game/Art/CoastalImports`，每个模型独立 FBX、原贴图、原骨架；`manifest.json` 记录对应关系。
- 弩手仍用已确认的 `TripoCrossbow` 源文件和动作。自爆尸使用最新导入的 `ExploderLatest` 模型/原始 Mixamo 骨架，复用已有自爆尸动作生成规则，通过骨名映射适配；旧压测源 `TripoExploder` 不替换。
- 头槌沿用 `SiegeAnimations.blend` 中实际使用的已修订撞击片段，不用旧的小幅撞击版本。
- 尸犬、Mixamo 普通尸、弓手缺失动作补为初版。没有改原骨架、网格权重或美术贴图。
- 烘焙成共享动画网格，使用原有实例化群体绘制和相机裁剪，不给几千个单位添加独立 Animator。
- 所有导入模型用原始烘焙颜色，不叠加新的模型照明。
- 牧场仅新增独立作物网格，坡面更矮略疏；房屋/屋顶/原贴图不变。

## 明确限制

- 这是可玩美术整合切片，不是全部兵种机制完成版。
- 希腊火放在营内演示原有转向动作，尚未接入可操控喷火伤害；炮塔/火塔仅作为建筑。
- 头槌和背笼巨尸暂时分别对应现有 `giant` / `boss` 临时数值与通用攻击；自损撞墙、抛尸技能尚未实现。
- 炮楼暂未启用友军专属穿门通道；当前城防封闭，破墙后双方可穿过缺口。
- 城墙预先布置，连续墙身只在端部有墩；拖墙、塔覆盖墙段的建造交互尚未在此切片接入。
- 其余建筑用途可共用已导入工坊外观；不表示这些建筑已经各有专属模型。
- 新导入 Soldier 及未绑定 Walker 源保留在项目资源中供检查，不重复部署；已绑定 Walker 用于战斗。
- 所有伤害/速度/血量等仍取 `balance/unit_balance.json`。没有给未定器械偷偷套伤害。

## 重建与验证

Unity 批处理执行 `ZombieGame.EditorTools.CoastalTools.build_player`：导入、烘焙并编译。
仅代码变更时执行 `ZombieGame.EditorTools.CoastalTools.rebuild_player`。
生成的 `Resources/CoastalBuildings` / `CoastalUnits` 不作为编辑源提交。
试玩包加 `-coastalSmoke` 可跑启动、建筑阻挡、破墙、交战和截图检查；仅该检查提前下达总攻并锁定截图镜头，结束释放。
原来的 FrontierMap 场景和已接受的僵尸接触约束未替换。

## 本机验证记录 · 2026-10-02

- Unity 6000.6.1f1 独立 macOS 程序，1440×900，400 守军 / 2000 僵尸。
- 19 条模型记录（含 2 个已有资源复用引用），7 个战斗外观绑定；所有绑定的移动帧均通过非静止检查。
- 35 秒交战采样平均 24.4 FPS，脚本模拟平均 21.0 ms，呈现提交平均 1.5 ms；这不是 60 FPS 达标，也不是万人性能结论。
- 507 次射击、182 只僵尸死亡、21 座防御/建筑受损；11 个破墙位置经 NavMesh 检查可通行；几何侵入计数 0。
- 友军墙身远程射击、普通建筑挡弹、海面不可走、完整建筑不可走均通过。全血建筑隐藏血条、加载卡顿不放大边缘平移步长通过。
- Python 工具语法检查、Unity 编译及本场景 smoke 通过；未宣称原 Frontier 场景的全套交互回归已全部重跑。
- 本轮关闭实时阴影，保留源贴图颜色；未减面，未修改统一单位数值，也未改已冻结的僵尸接触约束。
