## 本轮落实的造型

- 头槌：低头前倾、厚颈、宽阔低重心、与身体连成一体的厚额头；无手持锤、无投锤。
- 投尸：更高的驼背轮廓、不对称长投掷臂、木质背架、攀附小尸和抓握的小尸。
- 灰褐腐皮、暗红灰褐破布、旧木与麻绳；眼睛缩小、藏在眼窝中，不使用突出发亮的大眼球。
- 相交身体体块通过体素重构合为连续皮肤；肌肉、手脚和躯干不以独立球形关节拼接。
- 骨质额头用同一皮肤上的材质遮罩过渡，不再单独扣一块类似头盔的盖子。
- 侧后视与斜俯视一起检查；不会只用正面灯光遮住背面的模型问题。

概念图仍是目标；本版大形、纹理和布条是第一次三维转译，不宣称达到概念图细节或商业角色精度。模型比例、载尸数量只是美术提案，不写入 gameplay 平衡。

## 编辑与重建

打开 `.blend` 后，主体选中，默认显示评审相机。按小键盘 `0` 切换相机视角；中键旋转，滚轮缩放。
在右侧 Outliner 按身体、衣物、背架/乘员和评审环境分组查找对象。
主体可继续雕刻；布条、绳索、木架是独立对象，可隐藏、移动或单独调整材质。
没有安装第三方插件，也没有依赖外部付费模型/皮肤贴图。

重建命令（从项目根目录运行）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --threads 6 \
  --python-exit-code 1 --python tools/art/boss_models.py -- --boss all --resolution 1000
```

注意：该命令会重建并覆盖本地 `BossModels-v1` 生成文件。开始手工优化前，先在 Blender 用“另存为”保存到自己的新路径，不要直接修改生成目录后再运行重建。

制作源码：

- [boss_geometry.py](../../../tools/art/boss_geometry.py)：连续体块、皮肤、布条、绳索、木架。
- [boss_models.py](../../../tools/art/boss_models.py)：两种角色造型、材质、验证、相机和实际渲染。
- [verify_boss_models.py](../../../tools/art/verify_boss_models.py)：新 Blender 进程重新打开已保存文件，核对闭合性、连通性、渲染和人类母版哈希。
- [调研记录](RESEARCH.md)：所参考的流程与本轮实际做到的阶段。

## 尚未完成 / 不可误报

- 这是静态雕刻评审网格，**不是直接投放万人战场的低模**。
- 未完成动画拓扑重建、UV、贴图烘焙、LOD、骨架和动作，也未测试 Unity 中的材质或性能。
- Blender 的程序材质不能假定直接导出后在 Unity 保持相同外观；定稿后需要烘焙和着色器适配。
- 自损撞墙、投尸伤害、Boss 刷怪及游戏数值本轮未实现或更改。
- 现有人类母版、已有场景和游戏机制保持不变。

验证包含主体网格单连通、坐标有限、必要造型部件存在与网格三角形统计；不等于所有视觉穿插、蒙皮变形与游戏性能已经通过验证。

2026-09-28 实测：两份文件可重新打开，主体均为单连通且非流形边为 0；头槌约 22.0 万、投尸约 26.5 万网格三角形（不包含曲线转网格后的面数），所以明确不是游戏低模。投尸主体眼窝切割产生的 8 个微小孤立顶点已清除，验证仍要求所有主体连为一个表面。人类母版 SHA-256 保持原值。完整记录在评审目录的 `reopen_verification.json`。
