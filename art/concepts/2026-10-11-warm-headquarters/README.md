# 暖色主基地 · 两国三时代

用户最新方向：普通人类士兵与建筑保持旧稿暖色，窗灯不改；撤回整批冷色修订。这里只更新两国的六款主基地。

- 时代一／二：延续此前认可的新版布局、空地与建筑比例，恢复暖材质。
- 时代三：同样暂定5×5地块，中央建筑更高、层次更丰富，不通过放大整个村庄或门窗实现宏伟。
- 天朝：木构主导；高级深色木材、朱漆柱梁和斗拱，灰瓦；石材限于基座、台阶和铺地，不做石头城堡。
- 拜占庭：暖米灰石材、棕木与赤陶瓦，紫色旗幔；不用金属屋顶、金属包覆或金属装饰。

完整图像生成提示词、视觉检查、原生图片尺寸与哈希见两国 `fragment.json` 及总 `manifest.json`。`reference-inputs/` 为冻结的布局参考；`previous-warm/` 为替换前18张旧主基地独立PNG和目录清单，避免旧稿丢失。图片未伪上采样为4K。

当前Tripo主基地目录使用新版，其他士兵、普通建筑、武器、僵尸、器械输入及历史目录均不动。所有图仍是二维AI概念，不是标定施工图；跨视角局部细节在建模时统一。5×5是暂定概念占地，不代表自动修改游戏碰撞、导航或建筑规则。

本轮没有编辑Blender模型、Unity资产、灯光、日光或游戏数值。老巢原15张保留：整体紫色感染与阴暗氛围统一，部分砂岩、土坯、茅草仍暖，不宣称全是冷色。
