# 建筑与三个时代（2026-09-28 新版设计）

状态：用户确定的建筑清单与解锁规则；本轮仅更新设计文档和二维概念图，未接入 Unity、未建立可运行建筑或修改平衡数值。主基地首稿被指出过小，最新图使用更高大、气派的雄伟版。随后用户取消两国城堡，拜占庭改为大浴场，并增加分时代防御塔。

## 1. 时代解锁

后一个时代保留之前时代全部建筑；小村庄、长城仅天朝可建；大浴场、喷火塔仅拜占庭可建。天朝取消城堡后不擅自新增替代人口建筑。

| 时代 | 本时代新增建筑 |
| --- | --- |
| 一时代 | 伐木场、采石场、打猎小屋、渔场、仓库、木头房、小村庄（天朝）、兵营、哨站、木墙、木门、箭塔 |
| 二时代 | 农田、铁矿厂、弹药库、石头房、箭坊、石墙、石门、炮塔 |
| 三时代 | 火药库、火药坊、工程营、大浴场（拜占庭）、长城／蜂巢炮（天朝）、喷火塔（拜占庭） |

主基地有三个时代外观；升级费用、时间、人口与前置条件待定。新增箭塔、炮塔、长城、喷火塔按用户明确的一、二、三时代解锁，不直接沿用历史文档旧数值。两国城堡均已取消，旧图仅供追溯。

### 防御塔结构与地面通行（2026-10-05）

- 两国箭塔、炮塔和拜占庭喷火塔：下部为方形底面的垂直长方体实心石墩，顶部沿用对应阵营已确认塔楼与武器。
- 天朝长城／蜂巢炮建筑保留长条长方体石墩与顶部武器平台，不添加地面门洞。
- 石墩无门、窗洞、梯子、阶梯、外棚和下部装饰；石材块缝属于材质。顶部原有楼阁门和平台台阶不构成地面通路。
- 防御塔、木墙、石墙及武装长城阻挡友军与僵尸。取消此前友军穿过炮楼的设计；防线通行只由木门、石门承担，不能把普通石墙或塔当作门。
- 概念图六种方案共 18 张独立视图已原路径更新，见 [Tripo 建筑导入说明](../art/concepts/tripo/README.md#建筑54-个方案各三张)。占地沿用用户后续确认的宏伟等比例模型尺寸，不在这次图像修订中重新指定 2×2 或战斗数值。

## 3. 哨站与视野

- 用户明确：我方建筑必须位于哨站覆盖内才能运作。
- 哨站用高处瞭望平台、灯火和旗帜表现覆盖节点；图中不画攻击武器，不擅自增加攻击能力。
- 哨站覆盖是“建筑运作条件”，不等同于战争迷雾视野；保留已确认的全部存活友军与未感染建筑提供共享视野的规则，不把视野错误地改成仅哨站提供。
- 待确认：覆盖半径；按建筑中心还是全占地判定；覆盖外禁止放置还是允许放置但停工；覆盖失效后的库存、人口和训练如何处理。
- 待确认：开局主基地是否自带覆盖，或预置一座哨站，避免“无哨站便无法建可运作哨站”的循环；哨站自身、城墙/城门是否适用同样覆盖条件。
- 既有弹药库补给圈与本轮拆分成箭矢库/火药库的规则尚未迁移；不把“存储容量”和“部队补给范围”混作同一功能。

## 4. 两国视觉语言

### 天朝

- 灰瓦、红柱、木构、灰石台基、适量红旗，保持东方军事聚落。
- 主基地从一时代起便是高大宽阔的军政主殿；后续时代增加侧殿、台基与屋顶层级，而不是一时代普通民房。
- 作坊和民居保持实用体量，不把每栋经济建筑都画成宫殿。
- 小村庄由紧凑木屋组团构成，表现大量人口而非豪华石制建筑群。

### 罗马／拜占庭

- 暖灰浅石材、砖带、圆拱、陶瓦、紫色布幔旗帜和少量旧铜饰件。
- 主基地为宏伟的世俗军政大厅；高级核心可加入圆顶和回廊，普通经济建筑不都做教堂。
- 拜占庭没有小村庄，改以用户新增的大浴场表现大型公共建筑：拱廊、圆顶、可见浴池与紫色布幔；取消堡垒垛口，不擅自赋予驻军或治疗能力。
- 两国同职能建筑保留相近可读性，差异不只是换颜色，而是结构、屋顶和材料体系。

### 建模建议（不是已实施预算）

- 共享屋顶、梁柱、门窗、墙段模块；平铺材质与贴花表现瓦缝、木纹和砖缝。
- 保留识别性轮廓：伐木场木料、矿厂坑口、箭坊工作台、仓库装卸口、哨站高灯台。
- 微小杂物和过密瓦片不要逐件建模；根据实际镜头做 LOD，暂不承诺面数与万人帧率。
- 概念图的院墙与装饰不自动转为碰撞体、可驻扎建筑或免费防御功能。
- 三视图属于建模方向参考，仍需统一跨视图结构，不能直接当精确施工图。
