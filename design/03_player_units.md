# 玩家兵种 / Player Units

## 共用人物＋独立武器 · 2026-10-05

- 两个阵营分别保留民兵、老兵、精英三个基础人物，共六个身体模型。每个模型准备空手 T-Pose 正／侧／背三张独立图：每国九张，两国十八张；不再为弓手、弩手、枪手分别重复生成同等级人体。
- 保留两国衣服、头盔、甲胄和手部等级差异；基础人体不带武器、盾牌、箭筒、投矛束等兵种挂件。通用腰带可保留。
- 现有八个阵营武器外观各提供一张独立图。武器与身体分别在 Tripo 生成，再在 Blender 主布局装配、绑定到手部／武器骨骼并检查握持；不假定旁置武器会被自动抓取或正确蒙皮。
- 同兵种各等级共享兼容骨架上的动作；不同武器仍用各自攻击／装填动作。共用模型不合并兵种、射程、伤害、弹药规则，也不改变运行时 balance。
- 原分兵种人物图保留为历史外观参考，不再作为当前建模数量；当前输入见[Tripo 导入清单](../art/concepts/tripo/README.md)。本轮是二维参考制作，没有替换正式游戏模型或完成新的绑定。

## 步兵三级外观 · 2026-09-29

- 用户确认方向：同一种步兵分为**民兵／新兵 → 老兵（暂名）→ 精英**三个等级，并拥有不同皮肤。中级名称尚未正式定案；“十长”不直接等同所有步兵的经验等级。
- 现有两国八种步兵概念图全部保留，作为精英级外观；新增两国民兵、老兵共四张阵容图，包含 16 个等级外观方案，见[概念图总册](../art/concepts/README.md#步兵等级皮肤--2026-09-29)。新图待评审，不是已经接入 Unity 的模型。
- 外观递进（民兵 v2、老兵 v3）：民兵保持褪色灰褐布衣、少量补丁、旧腰带与布帽，红／紫色仅作阵营布带标识；老兵比民兵稍有加强，两国均采用纯皮革身体甲胄。天朝恢复之前分瓣、护耳护颈的传统头盔与短红缨，皮甲采用穿着式交叠皮片、皮绳与缝边，不是现代方形防弹背心；拜占庭躯干锁子甲换为皮革胸甲与短皮裙片，保留紫衣和素铁盔。精英仍沿用已认可的完整甲胄及装饰。同阵营同等级共用甲型，以武器识别兵种；新甲型仍待评审。
- 三个等级都保留长袖。2026-09-30 最新手部规则：两国民兵裸手、老兵棕色皮革手套、精英锁子甲手套；天朝精英另有小型东方叠片覆手甲和短红边袖口，属游戏化设计而非历史制式复原。天朝精英保留原有铆钉，老兵取消身体甲上的铁片和金属铆钉；头盔和武器不改为皮革。阵营仍以天朝红色、拜占庭紫色识别，不只靠换色区分等级。拜占庭弓箭手参考姿势不手持散箭，弓和箭筒保留。
- 这是熟练度／部队等级的外观方向，不与主基地的三个时代自动绑定，也不把弓手升级成弩手等其他兵种。
- **未定项**：经验获得方式、升级门槛、是否消耗资源、属性增益、补员或死亡后的等级规则。全部保持待定，本轮不写入 `unit_balance.json`、不创建场景局部数值、不改已冻结人体和骨骼。

## 两国阵营增量 · 2026-09-28

- **天朝**：弓箭手、诸葛弩手、普通弩手；原火枪手改为三眼神铳兵，三连发每轮消耗 3 发弹药，射程比单发火枪少 1 格。“威力低一点”本轮暂按单发伤害较低理解，具体伤害及连发间隔仍待确认，不写入运行时。
- **罗马（拜占庭）**：罗马军团投矛手、弓箭手、普通弩手、单发火枪手。投矛具有穿透效果，射程比弓箭手少 1 格；穿透目标数、衰减等未定。弓箭手与弩手沿用天朝对应机制，替换为罗马外观。
- **统一甲型**：罗马四步兵共用同款头盔、钢制片甲、护肩、护臂、裙甲与靴子，以紫色布料、旧金属和少量金色纹样区分阵营，仅武器、军需挂件与投矛盾牌不同。天朝保持既有红甲体系；不把两国混成同一种服装。
- **罗马工程器械概念**：巨型重弩、投石机、希腊火喷射器；希腊火替代蜂巢炮，表现为持续喷火器械，不是火箭箱。本轮按罗马替换关系制图；天朝是否也移除蜂巢炮需用户确认，旧图仅归档，不据此擅自删除天朝设计或运行时资源。
- **重弩修订**：明确巨型横弓、单根中央箭槽、单支粗弩箭与后部绞盘，禁止先前“钥匙头”状空框结构。
- **全部人类步兵长袖，手部按等级区分**：民兵裸手、老兵皮手套、精英锁甲护手，以本页最新规则为准。远景简化掌体与握持轮廓，保留拇指和必要的扳机食指；锁子环用纹理，不逐环建模。保留天朝精英大而稀疏铆钉。具体减负建议见概念总册；不在本轮改动已冻结模型。
- 本轮为二维概念设计与文档同步，不增加可玩单位、不修改数值唯一源、不制作或导入新模型。

### 武器与动作约束

- 弓箭手、诸葛弩手、普通弩手是三个独立兵种，不把“诸葛弩弓箭手”合为一种。
- 诸葛弩表现木质连发装置，不使用现代弹匣步枪轮廓；普通弩不是缩小的工程重弩。
- 火枪是东方火绳枪，不是现代步枪；保留约三秒的枪口烟雾方向。
- 弓弩使用箭矢体系，火枪使用火药体系；携弹、补给、切刀继续走现有正式系统。
- 概念图中的姿势仅供制作参考，不代表模型、骨骼或动画已经完成。

## 三种工程器械

这是移动军队中的工程器械，不是三座新塔；[防御建筑](07_defensive_buildings.md)是另一类系统。
本轮以以下三种替换旧“重弩炮 + 火炮”的设计名单。

### 1. 巨型重弩 / Giant Ballista

- 定位：重型弩箭输出，突出对大型目标的作用，穿透细则待测试。
- 外观：巨型横弓、粗大箭槽、木轮车、绞盘、铁箍，体量明显大于普通弩手武器。
- 用户确认：**可以移动，也可以固定架设**。
- 概念图用收放支脚和轮挡表达两态；转换时间、能否移动射击待确认。
- 沿用箭矢军需方向，消耗从共享配置确定，不以旧稿倍数作为定值。
- 已有 `heavy_ballista` 旧原型，不等于新架设机制已实现。

### 2. 投石机 / Trebuchet

- 定位：重型抛射与阵地火力支援，落点和范围伤害细则待测。
- 外观：高木架、长投臂、投索、重物、轮式底盘。
- 用户确认：**可以移动，也可以架起来**。
- 概念先采用配重式结构作为外观提案；行军时投臂放低捆扎，架设时展开支撑。
- 弹药如何计入现有石材/军需资源、操作人数和架设耗时待定，不新增未经确认的资源类型。
- 尚无对应新共享单位记录或完整实现，不能把旧火炮改名便视为完成。

### 3. 蜂巢炮 / Nest-of-Bees Launcher

- 定位：多发火箭齐射、压制密集尸潮，与单发巨弩、抛石形成差异。
- 外观：东方木轮车上的矩形密集发射管箱，可倾斜射角；不是单管西式火炮或现代火箭车。
- 用户提出《帝国时代 IV》朱熹系蜂巢炮作为方向参考，制作原创外观，不提取游戏资产。
- **最终外观：发射筒正面不露箭头、箭杆或箭尾，默认弹药完全装在筒内；车旁设置成排备用箭。架设与行军两态都遵守。** 此设定取代先前“露出箭头”的评审要求。
- 概念图提供行军和支撑展开外观；是否强制架设后射击、齐射节奏、装填和消耗尚待确认。
- 使用火药军需方向；旧 `cannon` 仅是原火炮原型，不代表蜂巢齐射已实现。

## 当前评审与暂缓项

- 步兵保留统一人体、红色布面铠甲、圆头盔、大而稀疏的铆钉；通过武器剪影区分，不为每种单位重做人体。
- 器械检查斜俯视轮廓、行军/架设差异、筒内藏箭与车旁备用箭的表达、材质与比例。
- [概念图及完整提示词](../art/concepts/2026-09-27/README.md)是二维评审稿，不是 Blender 模型或 Unity 实机图。
- 木盾兵、铁盾兵、玩家自爆兵移入暂缓/历史方案，不计入当前 7 种核心名单，本轮不启用。
- 骑兵、英雄与剧情兵种继续暂缓。
- 设计名称映射：连弩手 → 诸葛弩手；重弩手 → 普通弩手；重弩炮 → 巨型重弩；旧火炮退出设计名单，加入投石机与蜂巢炮。
- 本次不删除旧运行时 ID、训练按钮、存档引用或数值。实际接入时再统一迁移并补战斗回归，不将文档变更误报为已完成游戏迁移。
